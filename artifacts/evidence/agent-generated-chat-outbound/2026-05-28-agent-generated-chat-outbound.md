# 2026-05-28 Agent-Generated Chat Outbound Evidence

## Change Under Test

Product notifications are no longer final user-visible prose generated by
Gateway. Gateway now stores structured notification facts, enqueues a
`product_notification` inbound event to the bridge, and the worker Interaction
Agent produces the outbound chat message. The bridge dispatcher carries the
notification id back to Gateway for best-effort delivery reconciliation.
