# Product Requirements

This directory is the canonical home for current Coke product requirements.

- `current.md` is the normative product baseline: user goals, user journeys,
  required product behavior, boundaries, and user-visible acceptance criteria.
- Implementation status, legacy comparisons, gap analysis, bug evidence, and
  prioritization do not belong here. Put those records in `docs/issues/` or in
  dated execution plans.

Product requirements describe what the product must do for users. They must not
depend on how legacy implemented the behavior or whether current code already
passes it.
